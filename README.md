# Betre Mussie Basic Saving and Loan Organization

**Location:** Wollo, Kombolcha, Kirunak Café, 2nd Floor

## Deploy online

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Betelwon/betre-mussie)

Click the button above to deploy the application to your Render account. Render will read the `render.yaml` Blueprint in this repository and create the web service.

The application uses:
- Node.js + Express
- SQLite with persistent storage
- Member registration and photos
- Savings and loan records
- 5× savings loan limit
- Admin/teller login
- Loan repayment tracking
- Bank of Abyssinia account: 91929317

Default first login:
- Username: `admin`
- Password: `admin123`

**Change the default admin password immediately after first login.**
